Online Retail Data Analysis

Project Overview

This project analyses online retail transaction data to understand sales performance, product performance, and country-level sales patterns.

Objectives

- Clean and prepare transaction data.
- Analyse monthly sales trends and growth.
- Identify leading products and countries by net sales.
- Calculate average order value.
- Validate analytical results using SQL.

Tools Used

- Python
- Pandas
- SQL
- SQLite
- Matplotlib
- Microsoft PowerPoint
- Microsoft Word

Project Structure

- "data/" — raw and processed datasets
- "scripts/" — Python data exploration, cleaning, analysis, and SQL validation scripts
- "reports/" — charts, business report, and presentation
- "sql/" — SQL queries, where applicable

Key Findings

- Total net sales: £9,748,131.07
- Cleaned records: 536,639
- The United Kingdom accounted for approximately 84% of total net sales.
- November 2011 recorded the highest monthly net sales.
- An unusually high-value invoice was identified for further investigation.

Data Quality

The raw dataset was preserved separately from the cleaned dataset. Python and SQL were used to validate important results.

Recommendations

- Explore opportunities in markets outside the UK.
- Investigate unusually large transactions.
- Analyse postage-related entries separately from physical products.
- Verify December 2011 data completeness before interpreting the sales decline.
